# NoiseMD

This repository is used to hold supplementary files for the MSci project "Molecular Dynamics Modelling of Environmental Effects on Current-Driven Atomic Waterwheels

The relevent files are found in the NoiseMD folder:
- NoiseMd.py is the molecular dynamics code used to produce the results of the investigation, a discussion of the code is found in Appendix A of the thesis
- Energymovie.gif is an animation of the total energy progression over time, it is an animation of Figure 3.2 in the thesis
- trajectory2.gif is an animation of the trajectory of the atom in time. It is an animation of Figure 3.1 (left)
